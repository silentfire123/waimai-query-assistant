# 外卖查询助手

在安卓手机或电脑上按需查询**小蚕的美团满返／固定返和比例返**，对比同一门店的两类活动，展示接口提供的活动时段，并试算返后预计净支出。

只读查询，不自动报名、下单或扫描。名单重合不代表返现可以叠加，金额计算不保证到账。

## 当前版本

**1.0.6 / versionCode=9** 已在本机构建，尚未发布 GitHub Release。此版本移除歪麦渠道，增加活动时段、同店活动分区与查询数量摘要，见 [1.0.6 说明](docs/release-1.0.6.md)。已发布的 1.0.5 不包含这些变更。

本地安装包：`output/android/1.0.6/waimai-assistant-1.0.6.apk`；同目录有 `SHA256SUMS.txt`。沿用原测试签名，可覆盖安装；不要先卸载或清除应用数据。安装与构建见 [安卓说明](android/README.md)。

## 手机使用

- 手机独立运行，电脑关机不影响；查询活动与地址搜索仍需联网。位置和结果各自保存在当前设备，暂不跨设备同步。
- 设置位置 → 获取当前位置；识别成功即保存，不需要地图 Key 或手填经纬度。失败时保留旧位置，也可搜索附近小区／公司并选中保存。
- 手动查询，小蚕满返与比例返各自最多 10 / 20 页，默认 20 页。页数是请求上限，不保证全量，也不会扩大配送半径。
- 同店卡片分成“满返 / 固定返”和“比例返”。每组先展示一条，多条活动可展开；计算器仍可切换其他活动。
- 活动时段按接口返回的开始、结束时刻显示，标注北京时间；跨午夜显示“次日”。缺失或非法值显示“活动时段未提供”，营业时间不代替活动时间。
- 本次匿名首屏实测取得满返活动时段；比例返没有返回时间字段，保留未知。旧缓存也不会凭空补出时间。
- 查询完成后显示两类店数、确认重合家数及待确认候选对数；部分失败与历史结果会单独提示。
- 要求 Android 8.0 / API 26+ 和 Android System WebView / Chrome 105+。查询期间保持应用前台，被系统回收可能中断，已保存结果保留。

## 电脑启动

需要 Node.js 22+，无第三方运行依赖，不需要 npm install。

```powershell
npm start
# 或双击 启动网页版.bat
```

浏览器打开 `http://127.0.0.1:8787`。端口被占用时设置 `PORT` 换端口，保留用户已有服务。

电脑支持地址搜索、导入旧 PoC 位置或手填 GCJ-02 坐标。电脑浏览器 GPS 地址反查仍可用本人 `AMAP_KEY`；手机定位走系统地址服务与已有搜索，两者独立。

## 名单与数据

- 可靠美团门店 ID 或同来源可靠 ID 才确认同店；完整同名仅作待确认候选，不合并已知不同分店。
- 无名额、名额未知活动均保留；未知门槛不当作零门槛，缺金额不补零。上游未返回的活动无法恢复。
- 距离优先仍未核实。满返继续使用 feed，比例返继续使用已实测可用的美团专用接口；不因上游源码更新而替换为未验证的统一 feed。
- 升级后旧混合缓存只展示小蚕活动，重新计算店数和交集；原缓存文件及旧凭证保留，不再使用或发送歪麦 Token。下一次成功查询才更新名单，全部失败保留上次结果。
- 默认匿名；手机设置仅提供本人的小蚕 ID。本人标识不等于完整登录态，应用不自动读取微信配置。
- 电脑位置／结果在 `data/`；手机在应用私有目录，凭证用 Android Keystore 加密。诊断只含脱敏统计，不含位置、活动名单、凭证或原始响应。
- `.env`、`data/`、`output/`、日志、构建缓存与签名私钥不提交 Git，也不进入 APK。
