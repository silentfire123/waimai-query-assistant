# 外卖查询助手

本地自用网页版：比对小蚕中的「美团比例返」与「美团实付满返」，找同 ID 重合商家和同名待确认候选。

**不登录、不报名、不下单。名单重合不代表返现可以叠加；接口比例未核对实际到账。**

## 启动

需要 Node.js 22 或更新版本；没有第三方运行依赖，不用执行 `npm install`。

Windows 双击 **`启动网页版.bat`**，服务准备好后自动打开：

```text
http://127.0.0.1:8787
```

或在本目录运行：

```powershell
node server.mjs
# 或 npm start
```

关闭终端或 Ctrl+C 停止服务。仅监听本机，不向局域网或公网开放；手机暂不能直接访问。本地服务不能直接部署为公开服务。

端口被占用或系统保留时，可以设置其他端口：

```powershell
$env:PORT=8790
node server.mjs --open
```

## 第一次使用

1. 点击「设置位置」。如果电脑仍有旧 `waimai-helper`，可以明确点击「导入旧 PoC 已选位置」；只读旧配置，不修改它。
2. 或手动填写位置名称、GCJ-02 纬度、经度和 6 位行政区划代码。网页暂没有地图搜索或 GPS 转换，请使用与小蚕一致的坐标来源。
3. 选择每类最多 1–3 页，点击「查询重合商家」。只在点击时请求真实接口；轮询仅读取本机任务状态。
4. 查看「重合商家」「实付满返」「比例返」，可搜索当前名单，并展开采集说明。
5. 「查看演示」使用完全虚构的固定样本，不请求上游，也不覆盖真实结果。

每次仅运行一个任务；查询结束后冷却 60 秒。收到明确 WAF 拦截立即停止，不重试。页面刷新可以恢复任务；关闭服务会结束进行中的任务。

网页结果保存在 `data/latest.json`，位置在 `data/settings.json`。重启可恢复。查询全部失败保留上次名单，另外显示本轮错误；位置不一致的历史结果明确提示。旧 `output/live/result.json` 仅在没有网页缓存时作为未绑定位置的历史结果展示。

## 隐私和仓库边界

- `data/`、`output/`、`.env*`、`local-config.json`、`*-private.json`、日志和临时文件均不入 Git。
- 不提交真实地址、账号编号、凭证和原始接口响应。测试使用虚构数据。
- 默认匿名标识，不从微信读取凭证，也不复制参考项目作者账号。
- 如果将来需要本人数字 ID，仍沿用 `XC_SILK_ID`、`XC_USER_ID` 环境变量；两者必须同时设置，编号不等于完整登录态。不要上传这些值。
- 查询时经纬度会发送给小蚕接口以获取附近活动；除此之外没有分析、遥测、外部字体或第三方页面资源。
- 本机接口有 Host、同源和会话令牌保护，不是多人认证系统。公开部署前需补认证、配额、HTTPS 和服务器出口验证。

## 实现与测试

```text
poc.mjs         只读上游采集、去重、匹配、报告；兼容旧 CLI
server.mjs      本地 HTTP 服务、位置设置、任务、冷却和持久化
web/            无框架响应式网页
test/           Node.js 内置测试；虚构数据，模拟仅在上游边界
PRODUCT.md      产品范围
DESIGN.md       界面约定
DIAGNOSIS.md    既有 API 排查历史（最新结论优先）
```

```powershell
npm test
node poc.mjs --demo
node poc.mjs --pages 3
```

旧 CLI 默认只读 `../waimai-helper/config.json` 的已选地址；`XC_CONFIG` 可指定相同格式的其他配置。这是兼容入口，网页版使用独立位置，不依赖旧项目。CLI 结果仍在 `output/`；不自动同步网页缓存。

导入新旧响应：

```powershell
node poc.mjs --input .\responses-private.json
```

输入格式：`{"full":{"status":{"code":0},"feed_items":[]},"ratio":{"status":{"code":0},"list":[]}}`，也兼容满返 `promotion_list`。导入前移除无关隐私字段。缺数组或业务错误不当作正常空名单；`_demo: true` 始终标为演示。

## 接口和匹配边界

协议核对自 `lyrric/xiaochan` main 的 `XiaochanHttp.java`（2026-11-04），见 `THIRD_PARTY.md`。当前版本 `3.21.7.82`。

- 满返：`SilkwormFusion / FusionService.GetFeedPromotions`，`rebate_type=1`，仅 `source=1` 且 `store_platform=1`。
- 比例返：`SilkwormFusion / FusionService.GetMeiTuanPromotions`，读取 `list`。不以缺列表的 feed 类型 2 响应冒充空名单。
- 同一显式美团门店 ID 才确认重合；完整店名规范化后相同但缺共同 ID 只当候选。已知 ID 不同不匹配。不删分店名、不按品牌模糊合并。
- 小蚕 `store_id` 与美团 `wm_poi_id` 是不同命名空间，不能直接比较。
- `ratio / 100` 为百分数，金额 `/ 100` 为元；保留返回的用户比例及用户封顶字段。不承诺到账。
- 排除明确售罄，未知余量保留；活动时段、配送范围、个人资格和叠加规则未核验。
- 满返曾出现第二页重复，重复页自动停止；当前只是有限样本，不保证全量或附近没有重合。
