# 外卖查询助手

在安卓手机或电脑上按需查询小蚕、歪麦的美团返现活动，对比同一门店的满返／固定返与比例返，并试算返后预计净支出。

**只读查询，不自动报名、不下单、不自动扫描。名单重合不代表返现可以叠加，试算不保证到账。**

## 手机使用

- 当前版本：[1.0.4 自用测试版](https://github.com/silentfire123/waimai-query-assistant/releases/tag/1.0.4)，下载 Assets 中的 `waimai-assistant-1.0.4.apk`。标签按 `1.0.1`、`1.0.2`、`1.0.3` 依次递增。
- 1.0.4 保留无名额／名额未知活动、补齐四种来源组合并调整有界分页（versionCode=7），附 APK 与 SHA256SUMS.txt；沿用 1.0.3 测试签名，覆盖安装时不要卸载或清除数据。距离优先仍未打通，真机未完成验收，见 [发布说明](docs/release-1.0.4.md)。
- 手机独立运行，不依赖电脑开机或云服务器；**查询最新活动仍需联网**。电脑与手机各存一份位置和结果，暂不自动同步。
- 安装后打开「设置位置」→「获取当前位置」。成功即保存，无需再点保存；不需要配置地图 Key 或手填经纬度。也可搜索附近小区／公司，选中后保存。
- 定位依赖系统权限、精确定位、系统地址服务及上游地址搜索；失败时不覆盖原位置，可改用搜索选点。
- 选择采集范围后手动查询。查询期间保持应用前台；退出或被系统回收可能中断，已完成的结果保留。
- 同签名新版直接覆盖安装，**不要先卸载或清除应用数据**。卸载会删除本机位置、结果和凭证。

要求 Android 8.0 / API 26+，Android System WebView 或 Chrome 105+。这是自用测试版，**尚未完成 iQOO 15 真机定位、系统地址服务及端到端查询验收**；构建、单元测试和合成桥接检查不等于真机通过。

安装、架构和构建说明见 [安卓说明](android/README.md)。GitHub 代码库公开与否，不会把本机查询服务自动部署到公网。

## 电脑启动

需要 Node.js 22+；无第三方运行依赖，**不需要 `npm install`**。

Windows 双击 `启动网页版.bat`，或执行：

```powershell
npm start
# 自动打开浏览器（Windows）：node server.mjs --open
```

打开 `http://127.0.0.1:8787`。关闭启动终端或按 Ctrl+C 停止服务。默认只监听本机，手机不通过这个本机地址连接电脑。

端口被占用时：

```powershell
$env:PORT=8790
node server.mjs --open
```

首次使用：设置位置 → 搜索地址 → 选择并保存 → 手动查询。桌面版也支持导入旧 `waimai-helper` 的已选位置或手填 GCJ-02 坐标。**桌面浏览器 GPS 地址反查仍需服务端 `AMAP_KEY`，与手机免 Key 定位是两条不同实现**；不配置也可搜索选点。

## 查询与结果

- 网页和 APK 均提供小蚕两类各自最多 **10 / 20 页，默认 20 页**。这是扫描上限，不是配送半径或全量承诺；实际请求数、新增店数和停止原因会显示。歪麦只采集一次最多 **2 页混合类别**，不是每类各两页；即使配置凭证，本轮产品也不扩页。
- 保留小蚕、歪麦各来源活动；共同美团门店 ID，或同来源可靠门店 ID（限定美团活动）证实同店才确认重合；跨来源 ID 不直接比较，同名但缺可靠同店证据仅为候选。不同分店不因品牌相同而合并。
- **明确无名额（库存 0）和名额未知的活动均保留、展示并参与四种来源组合匹配**；缺失返现金额／比例等必要字段仍不伪造。名额、报名资格与金额完整性是不同维度。上游隐藏的活动无法恢复。
- **距离优先尚未打通**：小蚕满返沿用 `sort:1`，其距离语义未核实；比例返专用接口未找到可靠距离字段。歪麦使用上游综合排序。没有本地重排冒充距离优先；满返的 `is_show_mt:true` 也不声称是已核实的独占美团过滤。
- 「实付满返」包含返现金额明确的固定返；未知实付门槛不等于零门槛。歪麦未取得可靠独立会员返现金额／最低阶梯时，需要手填，最大阶梯不当作最低门槛。
- 计算器按订单实付、一份满返／固定返和一份比例返试算，可切换来源活动、补充缺失值；不核验账号资格或叠加许可。
- 每次一个查询，完成后冷却 10 秒。上游报错、要求登录或 WAF 拦截会停止相应流程，不绕过登录、不自动重试；部分名单明确标记。
- 「查看演示」使用虚构样本，不查询真实接口，也不覆盖真实结果。可搜索当前名单、导出脱敏诊断。

## 凭证、数据与隐私

默认匿名尝试。歪麦产品本轮最多两页混合类别，不尝试匿名第三页；本人凭证是否可用仍需实际核验，不能承诺完整名单或长期有效。

- 电脑可通过环境变量或 `node --env-file=.env server.mjs` 加载本人配置，示例见 [.env.example](.env.example)。`.env` 不自动加载、不上传。
- 手机「手机设置」保存本人凭证到 Android Keystore 加密的本机文件，不读取微信或电脑配置。
- 桌面本人歪麦会话验证工具与边界见 [WAIMAI-LOGIN.md](WAIMAI-LOGIN.md)，不要把凭证粘贴到聊天、Issue 或命令行参数。
- 桌面位置／结果保存在 `data/settings.json`、`data/latest.json`；查询全部失败时保留旧名单，位置不匹配的历史结果有提示。手机数据在应用私有目录。
- `data/`、`output/`、真实配置、日志、签名私钥、构建缓存不进入 Git，也不进入 APK。
- 查询会向小蚕／歪麦发送查询位置及所需身份字段；地址搜索、系统定位／地址服务、桌面可选高德反查也涉及相应服务。界面无分析遥测、外部字体或第三方页面资源。

`Dockerfile` 和 `PUBLIC_ORIGIN` / `ACCESS_PASSWORD` 提供通用封装与私人访问保护准备，**不是已上线的云服务**。公网模式还需 HTTPS、持久存储及上游出口验证，目前无已验收的零成本云部署地址。

## 开发与兼容 CLI

```powershell
npm test
node poc.mjs --demo
node poc.mjs --help
```

`poc.mjs` 是仍在使用的兼容 CLI／导出入口，默认仅查小蚕，支持 `--pages 1..10`（默认 5）；不与网页／APK 的 10/20 页范围混用。它可读取旧位置配置，输出到 `output/`，不自动同步网页缓存。`--input` 可导入本人脱敏的合并响应；导入结果标为未核验，不冒充实时查询。

| 文件／目录 | 用途 |
| --- | --- |
| `core.mjs`、`collector.mjs`、`waimai.mjs` | 双端共享采集、报告、匹配及多渠道聚合 |
| `platform.mjs`、`waimai-client.node.mjs` | Node 平台、存储资源及协议适配 |
| `server.mjs`、`web/` | 电脑服务与双端复用界面 |
| `android/`、`scripts/*android*` | 原生桥接、手机状态机、构建与 APK 资源检查 |
| `test/`、`android/test/` | 回归与 JVM 协议／网络策略测试，不是业务垃圾文件 |
