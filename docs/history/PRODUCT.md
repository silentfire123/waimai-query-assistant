# 外卖查询助手
> 2026-11-06 新对话实施入口：先读 [IMPLEMENTATION-HANDOFF-20261106.md](IMPLEMENTATION-HANDOFF-20261106.md)。Q1–Q16 已确认并批准在新对话实施；该文件定义新增目标，以下保留旧实现/历史状态，不代表新增功能已完成。


## Platform
本地 Web 应用；当前只允许本机 127.0.0.1 访问，不是公网或原生 App。

## 用户与任务
用户已认可 PoC 的小蚕美团「比例返 × 实付满返」名单对比效果，要求先做本地网页，再创建私有代码仓库。第一版按前轮方案作为自用工具实现，未来共享方式待确认。

## 已确认范围
位置设置、手动查询、两类名单、同 ID 重合与同名待确认、查询错误、最近结果。保留命令行。只读，不登录、不报名、不下单、不承诺叠加返现。

## 名单口径
用户于 2026-11-05 确认实付满返名单包含“固定返”，具体定义以 GLOSSARY.md 为准。门槛未知不等于无门槛；保留指定商品与评价条件，固定返也参与同店匹配。

## Stack
沿用已验证的 Node.js 核心与 HTML 结果的专业默认扩展：Node.js 22 内置 HTTP 服务 + 原生 HTML/CSS/JS，无第三方依赖。用户同意按照前轮本地网页方案执行；框架并非单独指定，未来可替换界面，保留采集模块。

## 成功标准
双击启动；设置或导入本机旧地址；手动查询；理解有限样本结论；重启后恢复最后结果；任何敏感配置或真实结果不提交 Git。

## 安全与证据
采集仅在主动点击时启动、单任务、结束后 10 秒冷却；网页默认每类最多 5 页，最高支持每类 10 页；遇 WAF 停止。查询设置使用 GCJ-02 坐标，当前沿用既有位置，不自动转换浏览器 GPS。历史位置和当前位置不一致必须提示。

## 当前行为（2026-11-06）
批准需求已在本地实现：小蚕/歪麦满返与比例返、多来源活动、10/20 页、返后预计净支出、地址选择与轻诊断。已知歪麦缺独立会员满返/最低阶梯字段只允许手填，不把最大阶梯当最低。云端仍未验收，详见 IMPLEMENTATION-STATUS-20261106.md，不能将这些目标当成已经上线。
